# Frame

## Register

product

## Users and purpose

A personal recording workspace for recording yourself and sharing your screen, editing the resulting video, and organizing video projects in folders. The primary journey is record, review, edit, export. The application runs in a browser and stores media locally on the current device.

## Confirmed direction

The user requested a dark interface throughout. The interface should keep recording, editing, and organization easy to discover. Additional choices below are implementation defaults rather than claims about the user's brand preferences.

## Implementation principles

- Make the next action obvious without overwhelming the workspace.
- Keep original recordings intact while saving edits separately.
- Explain camera permissions, save failures, and export progress in plain language.
- Use real stored projects and honest empty states.
- Provide keyboard access, visible focus, readable contrast, and reduced-motion support.
