# Frame visual system

## Scene and theme

A creator reviews video and records presentations at their desk, switching between the preview and controls. The user explicitly chose dark mode throughout, so the library, recorder, and editor share dark surfaces with readable controls.

## Strategy

Restrained color: ink and charcoal surfaces, cool off-white text, lavender-blue primary actions. Folder colors are secondary identifiers, always paired with names.

## Typography and layout

System sans-serif with tight heading tracking. Fixed rem hierarchy. A 228px sidebar anchors a flexible project workspace. The editor prioritizes the preview over settings. At narrow widths the sidebar collapses and panels stack.

## Components

Full subtle borders, 8-12px control radii, 16px major surface radii. Icons use Lucide at consistent stroke widths. Focus rings remain visible. Menus and dialogs support keyboard dismissal. Motion uses short opacity and transform transitions with reduced-motion alternatives.
